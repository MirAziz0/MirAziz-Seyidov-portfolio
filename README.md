## Tech

A single self-contained `index.html`: HTML, CSS and vanilla JavaScript, with no frameworks and no build step. The only external resource is Google Fonts (Poppins and Inter).

- Light and dark themes (follows the system setting; the choice is remembered)
- Responsive from phone to desktop
- Fade-in on scroll and an animated canvas backdrop, both disabled under `prefers-reduced-motion`

## Run locally

Open `index.html` in a browser. No install or server is needed.

## Deploy

Hosted on GitHub Pages from the `main` branch, root folder (Settings → Pages → Deploy from a branch).
