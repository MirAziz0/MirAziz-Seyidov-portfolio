01 · FEATURED

AI Job-Search Agent

Tool-using job-search agent with a hand-written LLM loop, 8 job sources and 151 offline tests.

  • Python
  • FastAPI
  • Pydantic
  • SQLAlchemy
  • React
  • TypeScript
  • Tailwind
  • Neon Postgres
  • Vercel
  • pytest
  • Hand-written LLM tool-use loop (no agent framework) with 7 tools: parse query, choose source, search jobs, fetch job details, score match, draft cover letter, update application status. Each step logs duration, tokens and estimated cost; 15-step limit per run.
  • 8 job sources: Remotive, Arbeitnow, Greenhouse, Lever and JSearch APIs, plus rate-limited, robots.txt-compliant scrapers for boss.az, hellojob.az and jobsearch.az, with cross-source deduplication.
  • Two-stage CV-to-job scoring: rule-based pre-filter, then the top 15 jobs scored 0–100 by the LLM against an explicit rubric (skills 40, seniority 20, location 15, salary 15, language 10) with reasons and missing skills; final score computed in code.
  • 151 offline pytest tests; backend and frontend deployed as separate Vercel services; LLM provider switchable between OpenAI and Anthropic.
